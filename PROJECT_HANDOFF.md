## 2. Architecture & Tech Stack

### Dashboard (Frontend)
- **Single HTML file** — `muki-tracker.html`
- Pure HTML + CSS + Vanilla JavaScript
- No build tools, no frameworks, no bundlers
- Runs locally in Chrome browser (downloaded file)
- **AI:** Gemini API (free tier) — branded as "AiMooki"
- **Storage:** Browser storage (window.storage artifact API) + localStorage
- **PDF parsing:** PDF.js CDN (cdnjs.cloudflare.com)
- **Fonts:** Syne + DM Mono (Google Fonts CDN)

### Server (Backend)
- **Node.js + Express** — `server.js`
- **Gmail OAuth2** — reads job alert emails
- **Firebase Realtime Database** — stores parsed jobs
- **Hosted:** Render.com (free tier — sleeps after 15 min inactivity)
- **Server URL:** `https://muki-job-server.onrender.com`
- **Firebase URL:** `https://muki-job-tracker-default-rtdb.firebaseio.com`

### Repositories (GitHub — mukilan122000-stack)
- `job-tracker-pro` — Dashboard HTML (private)
- `muki-job-server` — Server backend (private)

## 8. Important Product & Architectural Decisions

1. **Single HTML file** — entire dashboard is one file. No build tools. Customer downloads and opens in Chrome. Never split into multiple files.

2. **AiMooki branding** — AI engine is branded "AiMooki". Never mention Claude or Anthropic. All AI variables use `aiMookiResponse`, `aiMookiScore`, etc. CSS class `.am` applies the brand style.

3. **Paste-only resume in Analyser** — no upload button in Analyser tab. Upload only at onboarding. Resume pre-loaded from storage into Analyser box.

4. **Name locked after onboarding** — tied to license key, cannot be edited. Roles/skills/cities are editable.

5. **Source badges ARE the apply links** — no separate Apply button. Clicking the source badge (in/NK/IN/GD) opens that platform's job page.

6. **Deduplication client-side** — same company + similar role = one card with multiple clickable source badges.

7. **Auto-apply only fires when both Gemini scores ≥90%** — standard score + strict "harsh critic" second pass. Below 90% on second pass → manual review flag.

8. **One-time purchase + 90-day window** — not subscription. Renewal at ₹199/₹499/₹699.

9. **Firebase sync per license key** — planned Session B Part 2. Data restore when user re-enters key on new device.

10. **Mobile** — instruct Desktop Site / HTML Viewer app. No responsive rebuild needed.

11. **Git safety rule** — before every session: download latest HTML → git add → git commit → git push. After build: test in Chrome → if broken: `git checkout muki-tracker.html`. Muki is not familiar with Git — always give exact commands.

12. **Claude Code vs claude.ai split** — single HTML file changes = this chat. Multi-file server changes = Claude Code.

13. **V3 B2B play** — future: sell to colleges/placement agencies. NOT in current scope. Hold.

14. **Pricing finalised** — Plan A ₹499 / Plan B ₹1,499 / Plan C ₹1,999. All 90-day active. Discuss exact pricing details later.
