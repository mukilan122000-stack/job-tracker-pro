🤖 AiMooki Setup Guide

Applies while you sleep — or while you're at work.

✅ What's already done for you

✓ Your license key has been activated

✓ Your agent secret is pre-filled in the .env file

✓ The server running 24/7 in the cloud is set up

You only need to complete the 5 steps below — takes about 15 minutes.

1Install Node.js free

Node.js is what runs the AiMooki agent on your computer.

1. Go to nodejs.org → click the big LTS button to download

2. Run the installer → click Next → Next → Install (all defaults are fine)

3. When done, open Command Prompt (press Win + R, type cmd, press Enter) and type:

node --version

You should see something like v22.x.x. If you do, Node.js is installed ✓

💡 If you already have Node.js installed, skip this step.
2Get your free Groq API key free

Groq is the AI that reads job descriptions and fills in your application answers. It's free.

1. Go to console.groq.com → sign up (Google login works)

2. After logging in → click API Keys in the left sidebar

3. Click Create API Key → name it "AiMooki" → copy the key (starts with gsk_...)

⚠️ Save this key somewhere — you'll need it in the next step and it won't be shown again.
3Set up the AiMooki folder

1. Unzip the AiMooki folder you received to C:\AiMooki\
(or anywhere you prefer — just remember where)

2. Open the .env file inside the folder with Notepad

3. Find the line that says GROQ_API_KEY= and paste your Groq key after the = sign:

GROQ_API_KEY=gsk_your_key_here

4. Save the file (Ctrl + S) and close Notepad

💡 All other lines in .env are already filled in — don't change them.
4Run the one-click setup

1. Open the AiMooki folder

2. Right-click setup.bat → Run as administrator

3. A black window will appear and run through the setup automatically

4. When it says "Setup complete!", press any key to close

This does 4 things automatically:

  • Installs all required packages
  • Creates an "AiMooki Chrome" shortcut on your desktop
  • Sets up 3 scheduled tasks (9 AM scrape, 10:10 AM apply, 4 PM scrape)
  • Creates the folders it needs
⚠️ If Windows asks "Do you want to allow this app to make changes?" — click Yes.
5Set up your AiMooki Chrome & LinkedIn

AiMooki uses a special Chrome window to apply to jobs. You need to log into LinkedIn in it once.

1. Double-click "AiMooki Chrome" on your desktop (the shortcut setup.bat created)

2. A Chrome window opens — go to linkedin.com and log in with your LinkedIn account

3. Stay logged in (tick "Remember me")

4. Close this Chrome window — AiMooki will open it automatically every morning

💡 Only use this special Chrome for LinkedIn. Don't use it for regular browsing — it keeps your LinkedIn session alive for the bot.
✓Activate your dashboard

1. Open muki-tracker.html in Chrome (the file in the AiMooki folder — or the one shared with you)

2. Enter your license key when prompted → click Validate Key

3. You'll see the dashboard — it'll start showing jobs once the first scrape runs

💡 Bookmark this page. Open it anytime to see what AiMooki applied to on your behalf.

How it works day to day

You don't need to do anything daily. Just keep your laptop on from 9 AM onwards and stay logged into LinkedIn in the AiMooki Chrome window.

⏰ 9:00 AM — AiMooki searches LinkedIn and Naukri for fresh jobs matching your profile

⏰ 10:10 AM — AiMooki applies to the best-matching Easy Apply jobs (up to 15/day)

⏰ 4:00 PM — AiMooki scrapes again for afternoon job postings

📋 Check your dashboard once a day to see what was applied to and which jobs need your manual attention.

Common questions

My laptop was off at 9 AM — did I miss today's run?
The "Start When Available" option is enabled — if your laptop was off and you turn it on by 10 AM, it'll still run. If you miss a day, no problem — it picks back up tomorrow.

How do I check what it applied to?
Open muki-tracker.html → go to the Live Jobs tab → filter by Applied. You'll see every job it applied to with the exact answers it submitted.

Can I run it manually right now?
Yes — double-click run-aimooki.bat in the AiMooki folder. Make sure the AiMooki Chrome window is open and logged into LinkedIn first.

It's not applying to any jobs — why?
Two common reasons: (1) LinkedIn session expired — open AiMooki Chrome and log back in. (2) No jobs have been scored yet — wait until 10 AM and check the dashboard for jobs.

Something looks wrong — who do I contact?
Message the person who set this up for you. Tell them your license key and what you're seeing.

You're all set 🎉

AiMooki will start applying to jobs automatically from tomorrow morning.
Check your dashboard tomorrow afternoon to see your first batch of applications.
